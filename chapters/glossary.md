# Linux Commands Glossary

## A

**alias**  
Creates a shortcut for a longer command.

**apt**  
Package manager for Debian/Ubuntu systems.

**awk**  
Text-processing tool for pattern scanning and data extraction.

## B

**basename**  
Removes directory path from a file path.

**bash**  
GNU Bourne Again Shell, a common Linux shell.

**bg**  
Resumes a suspended job in the background.

**blkid**  
Displays block device attributes (UUIDs, labels).

**bootloader**  
Software that loads the operating system at startup.

## C

**cal**  
Displays a calendar in the terminal.

**cat**  
Displays or concatenates file contents.

**cd**  
Changes the current directory.

**chmod**  
Changes file permissions.

**chown**  
Changes file ownership.

**chroot**  
Runs a command with a different root directory.

**clear**  
Clears the terminal screen.

**cmp**  
Compares two files byte by byte.

**comm**  
Compares two sorted files line by line.

**cp**  
Copies files and directories.

**cron**  
Daemon for scheduling recurring tasks.

**crontab**  
Tool to manage cron jobs.

**curl**  
Transfers data from or to a server via URL.

**cut**  
Extracts columns or fields from text.

## D

**date**  
Displays or sets system date and time.

**dd**  
Low-level data copying and conversion tool.

**df**  
Shows disk space usage.

**diff**  
Compares files and shows differences.

**dig**  
DNS lookup utility.

**dirname**  
Returns directory part of a path.

**dmesg**  
Displays kernel messages.

**du**  
Shows directory/file disk usage.

## E

**echo**  
Prints text or variables to standard output.

**env**  
Displays environment variables.

**export**  
Sets environment variables for child processes.

## F

**fdisk**  
Partition table manipulation tool.

**fg**  
Brings a background job to the foreground.

**file**  
Determines file type.

**find**  
Searches for files and directories.

**free**  
Displays memory usage.

## G

**grep**  
Searches text using patterns (regular expressions).

**groups**  
Shows group memberships for a user.

**gzip**  
Compresses files using the gzip format.

## H

**head**  
Displays the first lines of a file.

**history**  
Shows previously executed commands.

**hostname**  
Displays or sets the system hostname.

## I

**id**  
Displays user and group IDs.

**ip**  
Modern tool for network configuration (interfaces, routes, addresses).

**ifconfig**  
Legacy tool for network interface configuration.

## J

**jobs**  
Lists active jobs in the current shell session.

## K

**kill**  
Sends signals to processes (commonly used to terminate them).

**killall**  
Kills processes by name.

## L

**less**  
Paginates file content for easy viewing.

**ln**  
Creates hard or symbolic links.

**locate**  
Quick file search using a prebuilt database.

**ls**  
Lists directory contents.

**lsof**  
Lists open files and associated processes.

## M

**man**  
Displays the manual page for a command.

**mkdir**  
Creates new directories.

**mount**  
Attaches a filesystem to a directory.

**mv**  
Moves or renames files and directories.

## N

**nano**  
Simple terminal-based text editor.

**nc (netcat)**  
Reads/writes data across network connections.

**netstat**  
Displays network connections (legacy tool).

**nice**  
Starts a process with modified scheduling priority.

**nohup**  
Runs a command immune to hangups.

## O

**od**  
Outputs file contents in different formats (octal, hex, etc.).

## P

**passwd**  
Changes a user password.

**paste**  
Merges lines from multiple files.

**ping**  
Tests network connectivity to a host.

**pkill**  
Kills processes based on name or attributes.

**pr**  
Formats text for printing.

**printenv**  
Displays environment variables.

**ps**  
Shows running processes.

**pwd**  
Prints current working directory.

## Q

**quota**  
Displays disk usage limits for users.

## R

**read**  
Reads user input in shell scripts.

**reboot**  
Restarts the system.

**renice**  
Changes priority of running processes.

**rm**  
Removes files or directories.

**rmdir**  
Removes empty directories.

**rsync**  
Synchronizes files and directories efficiently.

## S

**scp**  
Securely copies files over SSH.

**sed**  
Stream editor for text manipulation.

**seq**  
Generates sequences of numbers.

**shutdown**  
Shuts down or reboots the system.

**sleep**  
Delays execution for a specified time.

**sort**  
Sorts lines of text.

**split**  
Splits files into smaller parts.

**ssh**  
Secure Shell for remote login.

**stat**  
Displays detailed file information.

**sudo**  
Runs commands with elevated privileges.

**su**  
Switches to another user account.

**systemctl**  
Controls systemd services and system state.

## T

**tail**  
Displays the last lines of a file.

**tar**  
Archives files and directories.

**tee**  
Reads from input and writes to both file and output.

**top**  
Displays running processes in real time.

**touch**  
Creates empty files or updates timestamps.

**tr**  
Translates or deletes characters.

**traceroute**  
Shows the network path to a host.

**tree**  
Displays directory structure in a tree format.

## U

**umask**  
Sets default file permissions.

**uname**  
Displays system information.

**uniq**  
Removes duplicate lines from sorted input.

**unzip**  
Extracts ZIP archives.

**uptime**  
Shows how long the system has been running.

**useradd**  
Creates a new user account.

**usermod**  
Modifies a user account.

## V

**vi**  
Classic terminal text editor.

**vim**  
Improved version of vi with more features.

## W

**w**  
Shows logged-in users and their activity.

**wc**  
Counts lines, words, and characters.

**wget**  
Downloads files from the web.

**whereis**  
Locates binary, source, and manual files.

**which**  
Shows the path of a command.

**who**  
Displays users currently logged in.

**whoami**  
Shows the current username.

## X

**xargs**  
Builds and executes commands from standard input.

## Y

**yes**  
Repeatedly outputs a string.

## Z

**zip**  
Creates ZIP archives.
